# 温水猫CG角色训练营

温水猫CG角色训练：从生物解剖底层认知建立形体起稿逻辑
很多CG初学者画猫的角色时，一上来就盯着参考图里软乎乎的猫毛细节描，画出来的温水猫看起来永远像一个套着猫皮的毛绒玩具，身体结构松松垮垮，完全没有真实生物的力量感和柔软质感。温水猫这类软萌风格的CG角色，最核心的根基从来不是毛发细节画得有多逼真，而是底层形体结构完全贴合真实猫科动物的解剖逻辑，哪怕你一根毛都不画，只用素体模型就能让人一眼看出这是一只软乎乎的猫，而不是一个奇怪的异形生物。

温水猫的形体起稿，第一步要完全抛开所有毛发细节的干扰，用最基础的几何体搭建出完整的骨骼框架。很多人画猫的身体，直接把躯干画成一个均匀的椭圆，这是最常见的错误。真实的猫科动物躯干，胸腔部分的宽度明显大于腹腔，整个身体的骨架不是对称的椭圆形，而是前半段宽、后半段逐渐收窄的不规则形态，肩胛骨的位置向外微微隆起，连接前腿的支点明显高于胸腔的顶部。把这些骨骼支点的位置画准，后续整个身体的大形立刻就不会出现软塌塌的问题。

很多新手画出来的猫四肢永远显得比例奇怪，要么腿太长像个小细狗，要么腿短得完全站不起来。猫的四肢骨骼结构有一个非常关键的特征：它的腿看起来很短，但是大腿的大部分肌肉是藏在躯干的毛发里的，露在外面的部分主要是小腿和脚掌，很多人把大腿的长度全部算在露出来的部分里，最后四肢的比例完全失控。温水猫的风格本身就偏向软萌，你可以在真实解剖的基础上，把四肢的比例适当缩短一点，让它看起来更圆滚滚的，但是骨骼支点的相对位置绝对不能错，否则不管怎么调整都不会有自然的生物感。

头部的形体起稿最容易踩坑，很多人直接把猫的脑袋画成一个正圆形，五官全部摆在圆形的正面，画出来的脸永远像一个平面的贴纸。真实的猫头颅骨是一个前窄后宽的楔形，脸颊两侧的咬肌向外隆起，整个头部的侧面轮廓有非常明显的起伏，不是光滑的圆形。温水猫的风格可以把脸颊的隆起程度适当放大，让脸看起来圆乎乎的更可爱，但底层的颅骨结构逻辑不能丢，哪怕从侧面看，整个头部的体积感也能立起来。

形体起稿阶段完全不要碰任何毛发细节，把所有注意力都放在骨骼和肌肉的大形上。等你能只用素体形态就把温水猫的形体画得生动自然，后续所有的毛发、材质、细节工作才有坚实的根基，不然画出来的细节越多，整个角色的违和感反而越强。
